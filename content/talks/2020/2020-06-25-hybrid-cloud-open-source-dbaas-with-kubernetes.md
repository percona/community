DBaaS model for Databases is preferred by many teams due to simplicity, yet it typically comes with vendor lock-in and significant surcharge compared to infrastructure costs then deployed at Cloud Vendors.

With Modern Kubernetes though you can get DBaaS-like experience without those downsides as well as have ability to run same code onprem and on variety of the cloud. In this talk we will share general

principles about how such solution can be built as well as show Percona's Kubernetes Based Open Source DBaaS Solution
