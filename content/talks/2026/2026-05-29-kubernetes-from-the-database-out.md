If you already know databases and are new to Kubernetes, this talk will help you focus on the Kubernetes concepts that matter most for running databases. Rather than spending time on the usual discussion of  why  databases run on Kubernetes, we will go straight into  how  it works in practice. Using a PostgreSQL cluster on Kubernetes as a real example, we will explore the core components involved in day-to-day database operations, including storage, network connectivity, and the automation of restarts and upgrades. The goal is to provide a practical introduction to the key Kubernetes building blocks to start your Data on Kubernetes journey.
