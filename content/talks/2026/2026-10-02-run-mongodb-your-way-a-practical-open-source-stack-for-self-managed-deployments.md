Running MongoDB on your own infrastructure gives you greater control over data, security, and technology choices, but also means taking responsibility for security, backups, migrations, and search.

This session follows a platform team building a practical self-managed MongoDB stack using Percona Server for MongoDB, Percona Backup for MongoDB, Percona ClusterSync, and Percona Search. We’ll explore how these tools address enterprise security, backup and recovery, zero-downtime migration, and vector search for AI applications.

Attendees will leave with a practical reference architecture and a clear path to self-managed MongoDB.
