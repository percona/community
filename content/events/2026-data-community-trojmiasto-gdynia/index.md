## Radoslaw Szulgo — Vector Search: My Way or the Highway!

**18:15–19:15.** Vector search is in MongoDB Community Edition. That does not make it production-ready.

This was the first public presentation of **Percona Search for MongoDB**. Radoslaw walked the path from a proof of concept to running the stack on your own infrastructure: full-text, semantic, and hybrid search through RAG on familiar MongoDB data; the Day 2 problems that show up only in production (embedding pipelines, scale, authentication, monitoring, automation); and a reference architecture with automatic embeddings, enterprise authentication, and vector-index monitoring in **PMM**. The session closed with a live demo — a board-game search app on a working Percona Search stack.
